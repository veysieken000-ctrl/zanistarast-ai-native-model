# Zanistarast Publication Readiness Registry

This registry is a **pre-submission control surface**. Repository presence does not mean scientific validation, journal readiness, acceptance, or permission to submit.

## Mira-equivalent review rule

For this repository, manuscript preparation must be held to the same substantive standards expected from Mira: distinctiveness analysis, epistemic-status preservation, source/counterevidence review, analogy-versus-identity control, reproducibility/testability checks, and a reviewer-style challenge before venue formatting. The reviewer role must not manufacture evidence, grant scientific proof, or convert repository declarations into verified facts. A paper is revised from evidence; it is not made publishable by rhetoric.

The review sequence is: **Scientific review → Rasterast epistemic review → target-venue/editorial review → Müdebbir decision**. A failure at any review stage keeps the candidate out of the submission-ready state.

## Gate

A paper may move toward a venue-specific manuscript only after:
1. its distinct contribution is stated without cross-domain analogy being treated as identity;
2. empirical, computational, philosophical, religious, and repository-declared material are separated by epistemic status;
3. material factual claims have appropriate external literature support;
4. falsifiable claims specify observable variables, comparison/baseline, and failure criteria;
5. Rasterast review records unresolved gaps and counterevidence;
6. venue requirements are checked against the current official author instructions;
7. final submission remains a separate Müdebbir decision.

## Venue targeting rule

Do **not** force one journal template onto every candidate. First determine the paper's actual contribution and evidence type, then select a compatible venue class. Exact journal formatting, length, reference style, declarations, data/code statements, and submission files must be checked against that venue's current official instructions before conversion.

Repository candidates are not automatically manuscripts. A candidate without a defensible distinct contribution should be merged into a stronger Yek rather than published as a duplicate.

## Next controlled pass

The next pass should start with the strongest candidate, not mechanically rewrite every file. For that candidate:
- define one research question;
- separate claims from analogies and interpretations;
- build a literature comparison matrix;
- specify method, variables, baseline and falsification criteria;
- identify missing evidence;
- run Rasterast review;
- only then create a venue-specific manuscript package.

No external submission is authorized by this registry.
